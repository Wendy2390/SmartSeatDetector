## ❓ 常见问题（FAQ）
### Q：Java 后端启动报错 "Address already in use"？
A：说明 8080 端口被占用。在 IDEA 右上角运行配置中，把端口改成 8081。

### Q：小程序提示 "request:fail"？
A：确保 Java 后端正在运行，且手机和电脑在同一 WiFi 下。
